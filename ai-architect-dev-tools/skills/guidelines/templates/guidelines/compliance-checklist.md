# Compliance Checklist

Check before completing any implementation task:

- [ ] UI built from existing project or library components — no unnecessary new components
- [ ] Recurring UI constructs follow the documented standard patterns (see [UI Components](ui-components.md))
- [ ] No forbidden styling practices (see [Styling](styling.md)); design tokens used throughout
- [ ] New files placed according to the project structure table
- [ ] Naming conventions followed; all file names, identifiers, and CSS classes are English; domain terms follow the glossary (see [Naming & Language](naming-and-language.md))
- [ ] No hardcoded UI strings — i18n keys exist in all supported locales, without inline fallback texts
- [ ] State and data access follow the documented patterns
